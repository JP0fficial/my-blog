오늘은 클로드 코드와 함께 프레임워크 없이 이 블로그를 만들었습니다.
만들면서 웹 페이지를 이루는 세 가지 언어가 각각 어떤 일을 하는지 알게 되어 정리해 둡니다.

> 한 줄 요약: **HTML은 뼈대, CSS는 옷, JavaScript는 움직임**이다.

## HTML: 페이지의 뼈대

HTML은 페이지에 **무엇이 있는지**를 정합니다. 제목, 문단, 링크, 버튼 같은 요소를 태그로 표시합니다.

- `<header>`, `<main>`, `<article>`, `<footer>`처럼 뜻이 담긴 태그(시맨틱 태그)를 쓰면 구조가 한눈에 보입니다.
- 이 블로그에서는 `index.html`이 글 목록을, `post.html`이 글 하나를 보여주는 틀입니다.

```html
<article class="post">
  <h1 class="post-title"></h1>
  <div class="post-content"></div>
</article>
```

## CSS: 페이지의 옷

CSS는 페이지가 **어떻게 보일지**를 정합니다. 색, 글꼴, 여백, 배치를 담당합니다.

- **CSS 변수**로 색을 한곳에 모아 두면 다크 모드를 쉽게 만들 수 있습니다. 테마가 바뀔 때 변수 값만 바꾸면 됩니다.
- **미디어 쿼리**(`@media`)로 화면 크기에 따라 스타일을 다르게 줄 수 있어서, 모바일에서도 읽기 좋게 만들 수 있습니다.
- 한글은 `word-break: keep-all`을 주면 단어 중간에서 줄이 바뀌지 않아 훨씬 읽기 편합니다.

```css
:root { --bg: #ffffff; --text: #1f2328; }
[data-theme="dark"] { --bg: #0d1117; --text: #e6edf3; }
body { background-color: var(--bg); color: var(--text); }
```

## JavaScript: 페이지의 움직임

JavaScript는 페이지가 **어떻게 동작할지**를 정합니다. 사용자의 행동에 반응하거나, 데이터를 불러와 화면을 바꿉니다.

- `fetch()`로 마크다운 파일을 불러오고, 직접 만든 변환기로 HTML로 바꿔 화면에 넣습니다.
- 다크 모드 버튼을 누르면 테마를 바꾸고, `localStorage`에 저장해 다음에 와도 기억합니다.
- 마크다운 안의 글자를 그대로 HTML로 넣으면 위험할 수 있어서, 먼저 **이스케이프**(특수문자를 안전한 글자로 바꾸기)해야 한다는 것도 배웠습니다.

```javascript
const res = await fetch('posts/today-i-learned.md');
const text = await res.text();
```

## 세 가지를 비교하면

| 언어 | 역할 | 이 블로그에서 한 일 |
| :--- | :--- | :--- |
| HTML | 구조 (무엇이 있나) | 헤더, 글 목록, 본문 틀 |
| CSS | 표현 (어떻게 보이나) | 다크 모드, 모바일 레이아웃, 글꼴 |
| JavaScript | 동작 (어떻게 움직이나) | 글 불러오기, 마크다운 변환, 테마 전환 |

## 그 밖에 알게 된 것

1. 브라우저에서 파일을 그냥 열면(`file://`) `fetch()`가 막히기 때문에 **로컬 서버**가 필요합니다.
2. 프레임워크 없이도 작은 블로그는 충분히 만들 수 있습니다.
3. 만든 뒤에는 꼭 브라우저에서 직접 확인해야 합니다. 실제로 확인하다가 목록이 잘못 합쳐지는 버그를 찾아 고쳤습니다.
