# 픽셀 아트 에디터 — Review 결과

검증일: 2026-11-16 · 대상: `apps/pixel-editor/` (spec.md 기준) · 환경: `http://localhost:8000/apps/pixel-editor/`, 내장 브라우저(Chromium), Node

## 요약

- **통과**: 로직 29개 항목 전부, 그리기·단축키·팔레트·PNG 저장·저장/복구·반응형(360/1280)·테마·코드 점검.
- **수정 2건** (`main.js`): 포인터 캡처 실패 시 획이 시작되지 않던 문제, 지우개→펜 자동 전환을 스크린리더에 알리지 않던 문제.
- **남은 문제**: 큰 결함 없음. 실제 터치 기기와 스크린리더 확인, 체크무늬 대비(사양 값 그대로 약 1.2:1)를 눈으로 보는 일은 사람이 해야 함.

## 고친 내용

| 파일 | 무엇을 | 왜 |
|---|---|---|
| `main.js` `onPointerDown` | 획 상태(`stroke`)를 먼저 만들고 `setPointerCapture`를 try/catch로 감쌈 | 캡처가 예외를 던지면(포인터가 이미 사라진 경우 등) 획이 시작되지 않고 콘솔 오류가 남았다. 이제는 캡처 없이도 그리기가 이어진다(재검증 완료) |
| `main.js` `selectColor` | 지우개에서 펜으로 자동 전환될 때 알림을 "펜 도구, 현재 색: …"으로 바꿈 | 화면에는 도구 변경이 보이지만 스크린리더 사용자는 알 수 없었다 |

## 남은 문제 / 손으로 확인할 것

- 실제 터치 기기(iOS Safari, Android Chrome)에서 드래그할 때 페이지가 스크롤되지 않는지, 컬러 피커 동작 — 합성 이벤트로만 확인함.
- 실제 PNG 다운로드 파일 — 디스크 저장은 하지 않았고 blob 내용으로 검증함.
- 스크린리더(NVDA / VoiceOver)에서 `aria-live` 알림과 캔버스 레이블을 읽는지.
- 체크무늬 대비가 약 1.2:1로 은은하다. 밝기가 낮은 화면에서 잘 안 보이면 `--checker-b` 값을 조정할지 검토.
- 격자선이 칸 폭이 소수 픽셀일 때(예: 446.67px / 16) 일부 선이 조금 흐리게 보일 수 있음 — 기능에는 영향 없음.
