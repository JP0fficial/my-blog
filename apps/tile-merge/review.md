# 타일 합치기 — Review 결과

## 요약

- **통과**: 규칙(spec 10절 표 7건 × 4방향, `canMove`, 변화 없는 이동), 키보드·스와이프, 저장/복구, 게임 오버, 반응형, 테마 연동, 콘솔 오류 없음, 독창성.
- **수정 2건**: 타일 대비 미달 3곳(`style.css`, `preview.svg`), 막힌 판을 `over:false`로 저장했을 때 오버레이 없이 멈추는 문제(`main.js`).
- **남은 문제**: 실제 기기 터치, 스크린리더 낭독, `prefers-reduced-motion` 실제 환경은 손으로 확인해야 함.

## 남은 문제·손으로 확인할 것

- 실제 휴대폰에서 스와이프 감도와 게임판 위 스와이프 중 페이지가 스크롤되지 않는지.
- 스크린리더(VoiceOver/TalkBack/NVDA)로 점수 알림과 게임 오버 알림이 읽히는지.
- OS의 "동작 줄이기" 설정을 켠 상태에서 실제로 애니메이션이 없는지.
- 블로그 쪽에서 바꾼 테마가 앱에 반영되는 것은 같은 키(`theme`)를 쓰는 것으로 확인. 블로그 페이지를 오가며 깜빡임이 없는지는 눈으로 한 번 더 보면 좋음.
- 참고: 진행 중에는 포커스 위치와 무관하게 방향키를 가로챈다(spec의 "처리한 키만" 범위 안). 앱 화면이 한 화면에 들어가 실제 스크롤 손실은 없으나, 콘텐츠가 늘면 게임판 포커스 기준으로 좁히는 것을 고려.
